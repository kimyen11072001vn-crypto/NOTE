# NOTE - Student Feedback Management System

A comprehensive web application for teachers to manage student feedback, track progress, and communicate with parents.

## Features

- **Class & Student Management**: Create multiple classes, manage students
- **Quick Feedback Entry**: Enter feedback for multiple students efficiently
- **Skills Tracking**: Assess speaking, listening, reading, writing, vocabulary, grammar, behavior, homework, and participation
- **AI-Powered Comments**: Automatically generate feedback based on selected criteria
- **Attendance Tracking**: Mark attendance and track learning sessions
- **Data Export**: Export reports as PDF, Excel, or ready-to-send parent messages
- **Progress Analytics**: Visual progress tracking and skill analysis
- **Multilingual Support**: Vietnamese and English feedback templates
- **Mobile & Desktop Responsive**: Works seamlessly on all devices

## Project Status

## Technology Stack

- **Frontend**: React with TypeScript, Tailwind CSS
- **Backend**: Node.js with Express
- **Database**: PostgreSQL with Prisma ORM
- **Real-time**: Socket.io for live updates
- **AI Integration**: OpenAI API for comment generation
- **Deployment**: Docker, AWS/Vercel ready
- **Mobile**: React Native (optional future expansion)
