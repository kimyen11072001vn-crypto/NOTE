# NOTE - Feature Specifications

## 1. Class Management
- Create multiple classes
- Edit class information
- Delete classes
- Copy student lists to new classes

## 2. Student Management
- Add students manually
- Import students from Excel/CSV
- Edit student information
- Move students between classes
- Delete students

## 3. Quick Feedback Entry
- One-page feedback form
- Autocomplete for student selection
- Quick skill assessment buttons
- Template-based comments
- AI-generated comments
- Multi-language support (Vietnamese, English)

## 4. Skills Assessment
Assess the following skills:
- Speaking (Nói)
- Listening (Nghe)
- Reading (Đọc)
- Writing (Viết)
- Vocabulary (Từ vựng)
- Grammar (Ngữ pháp)
- Behaviour (Thái độ)
- Homework (Bài tập về nhà)
- Participation (Tham gia lớp học)

## 5. Feedback Templates
- Pre-built comment templates
- Create custom templates
- Save favorite templates
- Quick select templates

## 6. AI Comment Generation
- Select skills and levels
- Generate professional comments
- Support both English and Vietnamese
- Edit generated comments
- Save as templates

## 7. Attendance Tracking
- Mark presence/absence
- Track late arrivals
- Mark makeup sessions
- View attendance statistics
- Export attendance reports

## 8. Feedback History
- View all feedback for a student
- Filter by date range
- Filter by skill
- Export feedback history
- Print feedback

## 9. Data Export
- Export to PDF
- Export to Excel
- Generate parent reports
- Copy feedback to clipboard
- Email templates

## 10. Parent Communication
- One-click copy feedback
- Pre-formatted messages
- Zalo message templates
- Email templates
- WhatsApp integration (optional)

## 11. Analytics & Progress Tracking
- Student progress charts
- Skill improvement tracking
- Class-wide statistics
- Attendance trends
- Feedback frequency tracking

## 12. User Roles
- Teacher: Manage own classes and feedback
- Admin: Manage all teachers and classes

## 13. Security
- JWT authentication
- Password hashing with bcrypt
- Role-based access control
- Data encryption

## 14. Performance
- 10-20 seconds per student feedback
- Responsive on mobile and desktop
- Offline capability (sync when online)
- Real-time updates via WebSocket

## 15. Backup & Safety
- Automatic daily backups
- Data recovery options
- Audit logs
- Version history for feedback
